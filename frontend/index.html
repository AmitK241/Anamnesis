SYSTEM ARCHITECTURE — HOW ANAMNESIS THINKS

About

Anamnesis is a persistent memory layer for AI data agents, built on DataHub — designed so that every resolved incident becomes institutional knowledge the next agent inherits, instead of starting from zero.

The Problem

Every data team has felt this: a schema breaks, an engineer spends an hour tracing the root cause through lineage, writes a fix — and the knowledge dies with that conversation. Two months later, a different engineer hits the same class of problem and starts from zero again.

AI agents built on top of today's data stacks inherit this same amnesia. Without persistent memory, every agent run reasons in isolation.

How It Works
Built On DataHub

Every stage reads and writes through DataHub's MCP Server — lineage traversal for diagnosis, vector-indexed recall for memory search, and a custom IncidentMemory aspect written back to the graph so the knowledge compounds with every run, not just this one.

  • Bidirectional Graph Sync: Reads lineage via MCP Server & writes IncidentMemory aspects back to DataHub.
  • Cross-Execution Recall: Uses vector embeddings to prevent hallucination and duplicate investigation.
  • Production Quality: Clean open-source architecture with sample test suites and live demo setup.
